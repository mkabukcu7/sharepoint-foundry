# Multimodal Workplace Chatbot on Microsoft Foundry — Deliverables

This folder contains the deliverable set for the **Multimodal Workplace Chatbot Experiment on Microsoft Foundry** (Your Enterprise — AI4Ops Enablement).

| # | Document | Purpose |
|---|---|---|
| 1 | [`01-experiment-spec.md`](01-experiment-spec.md) | Experiment specification — goals, scope, functional/non-functional requirements, acceptance criteria (AC‑1…AC‑5), business scenarios. |
| 2 | [`02-architecture.md`](02-architecture.md) | Solution architecture on Microsoft Foundry — drafted with specialists, then reviewed & revised with an **AI Architect** and a **Cloud Solution Architect** (review log + review-driven revisions included). Contains mermaid architecture diagrams. |
| 3 | [`03-project-plan.md`](03-project-plan.md) | Project / delivery plan — workstreams, phased timeline, milestones, RACI, resourcing, risks, quality gates. |
| 4 | [`DEPLOYMENT.md`](DEPLOYMENT.md) | **Verified, step-by-step Azure deployment guide** — prerequisites, quota pre-checks, one-command deploy, smoke tests, troubleshooting, and teardown. |
| 5 | [`CONFIGURATION.md`](CONFIGURATION.md) | Environment-variable reference mapped to `.env.example` and the code. |

## How it was produced

1. **Spec** authored from the experiment brief.
2. **Specialist discussion** — Conversational AI/Agent, Data & Knowledge Engineering, and Security & Responsible AI specialists contributed design input.
3. **Architecture document** synthesized from that input.
4. **Architect review** — reviewed and revised with an AI Architect and a Cloud Solution Architect (both: *Approve-with-changes*; findings incorporated in §13–§15 of the architecture doc).
5. **Project plan** produced from the reviewed architecture.

> Mermaid diagrams in the markdown render in compatible viewers (GitHub, VS Code).
